I want to make an AI chatbot that can help indonesian elementary students learn. 
This chatbot will become an assistant that can assist student using hermeneutic didactics method to learn physical computing for example IoT, simple electronics, etc in elementary school level.

this ai tool will in form of a web based app, that has good UI/UX for elementary students and also easy to use both in mobile or in desktop.

this app will use bahasa indonesia

this app will in form of a rag app, and i will give knowledge such as IoT information, physical computing, and hermeneutic didactics method in educations.

in the future, this app will be deployed fully in gcp including the database.

step of implementation:
- local development
    - i will develop this and run this fully in local 
    - i will use qdrant as vectorDB (will use separate container from the app)
    - i will use free tier gemini as embedding tools
    - i will use the free llm api from openrouter (inclusionai/ling-3.0-flash:free)
    - i will use fast api and pydantic
    - i will use next.js as frontend, and i want the UI must be very good and responsive for elementary students (you can take inspiration from duolingo UI, but i want the UI is more futuristic and also colorful. try to use modern UI components and modern design principles. try to use animation and transition effects to make the UI more interactive and engaging)

- preparation for cloud deployment in gcp
